## What is [Data Cleaning Package name]?

### The Goal

Python library package designed to simplify and automate the process of cleaning and preparing datasets for analysis. It focuses on addressing common data quality problems, such as missing values, duplicate records, inconsistent data formats, incorrect data types, and unnecessary columns or rows.

The library will provide reusable functions and object-oriented classes that allow users to clean their datasets more efficiently without having to write repetitive code for every cleaning task. Users will be able to perform different data-cleaning operations through simple and organized methods, making the package easier to understand and use.

Developed using Object-Oriented Programming (OOP) principles, DataMend aims to demonstrate concepts such as encapsulation, inheritance, polymorphism, and abstraction in building a practical Python library. Its main goal is to help users transform raw and unorganized data into cleaner, more consistent, and analysis-ready datasets while reducing manual work and improving data quality.

### Features
- Data Loading
- Data Cleaning
- Basic Statistical Analysis
- Data Filtering
- Data Exporting
